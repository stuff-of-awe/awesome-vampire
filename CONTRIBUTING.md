# Contributing

Open an issue or pull request with a canonical URL, a short original description,
the appropriate section and the task or audience it helps. Disclose your affiliation.
Prefer project documentation, useful teaching material, reproducible examples and
primary research. Clearly label historical or version-specific resources.

For examples, include the Vampire version, exact command, input and observed output.
Do not call an example tested unless it was run. Preserve authorship and licence
notices when proposing imported material. Suggestions from across the community
are welcome; use of ECHIDNA or other Stuff of Awe projects is not required.

Report Vampire defects to its upstream project; use this repository for list
corrections. Follow the organisation's
[maintenance policy](https://github.com/stuff-of-awe/.github/blob/main/docs/collections/MAINTENANCE.adoc).
